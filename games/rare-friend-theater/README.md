# Rare Friend Theater

A five-act interactive comic starring the player's verified Rare Friends Generations NFT. Each Friend's sprite family gives them a stage role and color. Find a hidden star with the spotlight, play its lost lullaby note by note, cross a paper bridge, choose how your Friend rescues it, equip a stage prop, and view a five-panel comic of your story. Save the rendered image with the browser's image menu.

## Play locally

From the repository root, with Node.js 22+:

```sh
npm ci
npm run dev:game -- games/rare-friend-theater
```

Open the displayed URL, normally `http://localhost:4173`. Connect a browser wallet on Robinhood mainnet (chain 4663) that owns a hardwired Generations NFT of generation 1 or higher. The SDK verifies ownership before loading the game and supplies the selected Friend. No private key, RF funding, or transaction signature is needed for this simulated preview.

In the first act, move the spotlight with a mouse or touch and tap the hidden star when it appears. Keyboard players can focus the stage, aim with arrow keys, and press Enter. A "Reveal the clue" button provides a direct alternative. In act three, tap the three glowing notes in order, press Enter or Space on the focused stage, or use "Play next note." Choose one action per act, then continue. The five choices set the words and scenes shown in the PNG comic. Choose a Moonbeam, Sugarplum, or Mossy backdrop; the selected colors also appear in the comic. Use the browser's image menu to save it; downloads initiated inside the SDK's sandboxed iframe are blocked. The Backstage Prop Box lets you spend simulated RF to add a moon lantern, brass key, or star confetti to the scene and comic. Equip any owned prop at any time. Replay retains your session props and simulated balance; reloading resets them.

## Economy and implementation

- FriendSDK v0.1.3 supplies wallet connection, fresh ownership verification, selected Friend identity, and sandboxed game runtime. `client.read()` initializes the verified session.
- Each preview session starts with 8 simulated RF. Each prop costs 2 simulated RF. Props have no probabilities, payouts, or resale value. There are no consumables.
- The prop ledger is local React state, not the SDK's chance-game ledger. No wallet transaction or real token spend occurs. A future live implementation would need a dedicated contract action to debit RF from the Friend's canonical wallet and persist prop ownership. The SDK v0.1.3 does not provide this action or persistent saves.
- `game.json` contains the SDK's required chance-game schema but its ticket and outcome are unused by this experience and never shown as game mechanics.
- On-chain art reads use FriendSDK's `createFriendReader`; the verified Friend's sprite is drawn into the stage and exported comic. Art reads may require a working Robinhood mainnet RPC.
- All scene art is generated by this project's canvas code; no third-party assets are used.

Build a static preview with `node scripts/dev-game.mjs build games/rare-friend-theater`. The output is `games/rare-friend-theater/.friendsdk/preview/`.
